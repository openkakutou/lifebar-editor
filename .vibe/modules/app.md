# Module: app
**Role:** Application entry point. Mounts the app's root frame — a `web-ui-kit` `<wuik-app-shell>` with the app title (`<h1>`), version, and (item 007) Undo/Redo toolbar controls, plus the lifebar file input, the New Lifebar Wizard (item 006), the sprite sheet input, the elements editor, the save/export action, and the Keyboard Shortcuts panel (item 008) as main content — into the DOM, or a dependency-free error state if the design tokens stylesheet failed to load. Owns the `Set` of expanded elements-editor section indices, re-rendering the editor (with that same `Set`) after either the lifebar document or the sprite sheet store changes, or a new lifebar is created. Moves focus into the elements editor's first section toggle once a wizard-created document mounts. Is the only place that pushes onto the shared `CommandStack`: the editor's own `onEntryChange` observer reports what changed, `app` turns it into a `do`/`undo` pair and refreshes the Undo/Redo controls afterward; loading or creating a document clears that history first. Also the keyboard-shortcut dispatcher: attaches one `window` `keydown` listener that resolves the live-bound action off the shared shortcut manager and calls straight into Save/Export's/Undo's/Redo's own trigger functions, and keeps each of their buttons' shortcut-hint labels live. Tears down the previous render's `window` listener, button-label subscriptions, and the shortcuts panel's own manager reference before building a new one, since the shortcut manager (unlike the DOM) is a singleton that outlives any one render.
**Files:** `src/main.ts`, `src/version.ts`, `src/style.css`
**Exports:** `appVersion: string`, `renderApp(root, version, options?): void`, `designTokensLoaded(target?): boolean`
**Depends on:** `@openkakutou/web-ui-kit` (layout shell + design tokens, external package), `modules/input.md`, `modules/document.md`, `modules/editor.md`, `modules/wizard.md`, `modules/shortcuts.md`
