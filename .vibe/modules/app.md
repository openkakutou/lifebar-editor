# Module: app
**Role:** Application entry point. Mounts the app's root frame — a `web-ui-kit` `<wuik-app-shell>` with the app title (`<h1>`), version, (item 007) Undo/Redo toolbar controls, and (item 009) a `<wuik-locale-switcher>`, plus the lifebar file input, the New Lifebar Wizard (item 006), the sprite sheet input, the elements editor, the save/export action, and the Keyboard Shortcuts panel (item 008) as main content — into the DOM, or a dependency-free error state if the design tokens stylesheet failed to load. Owns the `Set` of expanded elements-editor section indices, re-rendering the editor (with that same `Set`) after either the lifebar document or the sprite sheet store changes, or a new lifebar is created. Moves focus into the elements editor's first section toggle once a wizard-created document mounts. Is the only place that pushes onto the shared `CommandStack`: the editor's own `onEntryChange` observer reports what changed, `app` turns it into a `do`/`undo` pair and refreshes the Undo/Redo controls afterward; loading or creating a document clears that history first. Also the keyboard-shortcut dispatcher: attaches one `window` `keydown` listener that resolves the live-bound action off the shared shortcut manager and calls straight into Save/Export's/Undo's/Redo's own trigger functions, and keeps each of their buttons' shortcut-hint labels live. The real bootstrap (`mount()`) awaits `i18n.initAppI18n()` before the very first `renderApp` call, so the first paint already has the right language; `renderApp` itself stays synchronous. Owns one `onLocaleChange` subscription (item 009) that re-translates the switcher's own label, the Undo/Redo/Save-Export buttons' text and shortcut-hint tooltips (computed directly here, never by re-calling `bindShortcutLabel`, which would attach a second manager listener per switch), and re-invokes the elements editor's and the wizard's own render calls — both hold no locale-sensitive state a fresh render would lose. Tears down the previous render's `window` listener, button-label subscriptions, the shortcuts panel's own manager reference, and this locale-change subscription before building a new one, since the shortcut manager and the active i18next instance (unlike the DOM) are singletons that outlive any one render.
**Files:** `src/main.ts`, `src/version.ts`, `src/style.css`
**Exports:** `appVersion: string`, `renderApp(root, version, options?): void`, `designTokensLoaded(target?): boolean`
**Depends on:** `@openkakutou/web-ui-kit` (layout shell + design tokens, external package), `modules/input.md`, `modules/document.md`, `modules/editor.md`, `modules/wizard.md`, `modules/shortcuts.md`, `modules/i18n.md`
