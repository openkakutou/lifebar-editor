# Module: shortcuts
**Role:** This app's keyboard shortcuts (backlog item 008), wired through `web-ui-kit`'s shared, headless `ShortcutManager` instead of a hardcoded key handler. `app-shortcuts.ts` is pure logic (no DOM): `APP_SHORTCUT_ACTIONS` names this app's three actual actions (Save/Export, Undo, Redo) with their default bindings (Ctrl+S, Ctrl+Z, Ctrl+Y) — there is no "add/remove element" action, since this app doesn't have one yet (see `.vibe/decisions/008`); `resolveAppShortcutActionId` normalizes a live `KeyboardEvent` into a combo string (a local port of `web-ui-kit`'s own unexported normalization rule, since it isn't part of that package's public API) and looks up which action currently owns it — default or user-rebound; `handleAppShortcutKeydown` dispatches to the matching handler, deferring Undo/Redo (via `isEditableTarget`) while focus is in a text field/contenteditable region so native in-field undo/redo isn't hijacked, while Save/Export always fires and always calls `preventDefault()`. `app-shortcut-manager.ts` is the module-level `ShortcutManager` singleton (`appShortcutManager`, scoped to its own `localStorage` key) every other part of this module and `app` (`modules/app.md`) shares. `shortcuts-panel-section.ts` mounts `web-ui-kit`'s `<wuik-shortcuts-panel>` in a collapsible section that starts expanded (unlike this app's other collapsible sections) since it's the only place this feature can be discovered; it returns the mounted panel element so a caller can unset its `.manager` before discarding it (that setter is the element's only cleanup path — it has no `disconnectedCallback` of its own). Its own header label (item 009) is kept live across a locale change via its own `onLocaleChange` subscription, re-translating only that label so a manually collapsed/expanded state survives untouched. `shortcut-label.ts` keeps a button's `title`/`aria-keyshortcuts` in sync with its action's live binding, returning an unsubscribe function for the same "caller must clean up before discarding" reason.
**Files:** `src/shortcuts/app-shortcuts.ts`, `src/shortcuts/app-shortcut-manager.ts`, `src/shortcuts/shortcuts-panel-section.ts`, `src/shortcuts/shortcut-label.ts`
**Exports:** `APP_SHORTCUT_ACTIONS: readonly ShortcutAction[]`, `AppShortcutHandlers`, `registerAppShortcuts(manager): void`, `isEditableTarget(target): boolean`, `resolveAppShortcutActionId(manager, event): string | undefined`, `handleAppShortcutKeydown(event, manager, handlers): boolean`, `createAppShortcutManager(storage?): ShortcutManager`, `appShortcutManager: ShortcutManager`, `renderShortcutsPanelSection(root, manager, options?): WuikShortcutsPanelElement`, `ShortcutsPanelSectionOptions`, `formatShortcutTitle(baseLabel, key): string`, `bindShortcutLabel(element, manager, actionId, baseLabel): () => void`
**Depends on:** `@openkakutou/web-ui-kit` (`ShortcutManager`, `WuikShortcutsPanelElement`, external package — typed locally in `src/types/web-ui-kit.d.ts` since the installed package ships no `.d.ts` of its own), `modules/i18n.md` (`shortcuts-panel-section.ts`'s own header label; `shortcut-label.ts`'s `baseLabel` parameter is supplied pre-translated by its caller, `app`, which also owns recomputing each button's tooltip on a locale change)
