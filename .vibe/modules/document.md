# Module: document
**Role:** In-memory representation of whatever is currently loaded, one store per format — the place later editor screens read from. The lifebar store holds the parsed document plus its file name, and (item 006) a JSON snapshot of the document taken whenever it was last known clean (loaded, wizard-created, or saved) — `hasUnsavedLifebarChanges()` diffs the live, possibly in-place-mutated document against that snapshot on demand, the New Lifebar Wizard's discard-guard. The sprite sheet store holds the file name, raw bytes (needed for later on-demand pixel decodes), and decoded sprite groups. `command-stack-store.ts` (item 007) is a third store shaped differently from the other two: a single shared `web-ui-kit` `CommandStack` instance (an object with its own `push`/`undo`/`redo` behavior), not a plain value to get/set — `app` pushes an edit's do/undo pair here, and clears it whenever a document is loaded or created, since a history entry closes over a specific document's section/entry indices.
