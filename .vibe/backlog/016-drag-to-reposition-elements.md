# Reposition elements by dragging in the preview

## Description
Element positions are edited as numbers. Let the user drag an element in the preview to set its offset, snapping optional, keeping numeric inputs in sync.

## Acceptance Criteria
- [ ] Dragging updates the element's offset values and the numeric fields
- [ ] Each drag is one undo step
- [ ] Keyboard nudge with arrow keys
